# `ledgerload`

The one way the commands, `web` and the parity harnesses load a ledger: `Load(ctx, loader.Source)` follows includes, discovers documents and recovers from syntax errors, then processes, and returns the Processed tree, the `Ledger`, the load diagnostics, and `Root`, `Includes` and `Sources`; its error is a load that cannot go on. `Result.Diagnostics()` is everything the ledger reports as one new list, the load diagnostics then the ledger's, for a caller that reports both alike (`check --json`, `web`); one that renders them apart (`check`, `query`) reads `LoadDiagnostics` and `Ledger.Diagnostics()`. `Result.With` processes the loaded tree again with directives added, in a new `Ledger`, without loading again (`import`'s Extracted directives). Outside tests, nothing else calls `Ledger.Process`.
