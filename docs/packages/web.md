# `web`

Local dev tool: binds to localhost, no auth, guards against path traversal. Loads the ledger through `ledgerload.Load`, reporting its load errors and validation errors. The server holds one immutable `snapshot` (`web/snapshot.go`) behind its mutex: the ledger, processed tree, root, includes and errors of the last load that went on and, when the last load could not go on, that error. `snapshot.reload` builds the next one and `reloadLedger` swaps it in; a handler takes `Server.snapshot()` once and reads only from it, and `snapshot.queryContext` builds the query context. After a load that cannot go on, the reports and queries keep answering from the ledger loaded before (an empty one, and no queries, when none was), `/api/source` reports the error (and, while loads fail, loads again on each request, answering a file it cannot read with no source and the error), and the includes are those the last load that went on resolved (the root's own as written when none went on). With `--watch`, every reload, a save's included, brings the watcher in step with the snapshot (`syncWatches`): it watches the directories of the ledger's files, diffed against the watcher's own watch list, and reloads on any event on one of the files. `/api/balances` takes a `valuation` of `units`, `cost` (the default), `market` or a currency to convert to and has the ledger value the balances; it rounds every amount to its currency's display precision (`DisplayContext.Quantize`). The reports keep the choice in `?valuation=`, which the sidebar's report links carry.
